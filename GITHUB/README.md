# Eliodata Snippet Hub

Manage WordPress snippets from your IDE with a native WordPress engine and a secure API bridge.

![Icon](assets/icon.png)

## Links

- GitHub: https://github.com/eliodata/eliodata-snippet-hub
- WordPress plugin: https://wordpress.org/plugins/eliodata-snippet-hub/

## English

### Overview

Eliodata Snippet Hub includes:

- A native snippet engine inside the WordPress plugin.
- A secure REST API bridge for IDE integrations.
- Remote snippet management from Trae AI and VS Code.

### Installation

1. Install and activate the WordPress plugin in `ide-snippets-bridge/`.
2. In WordPress, generate an Application Password in **Users > Profile**.
3. In your IDE extension, add a connection with:
   - Site URL
   - WordPress username
   - Application Password

### Main Features

- List, create, edit, activate, and deactivate snippets.
- Assign snippets globally or to specific content targets.
- Import and export snippets (JSON / NDJSON).
- Manage multiple WordPress sites from IDE tools.

## Français

### Présentation

Eliodata Snippet Hub inclut :

- Un moteur de snippets natif dans le plugin WordPress.
- Un bridge API REST sécurisé pour les intégrations IDE.
- La gestion distante des snippets depuis Trae AI et VS Code.

### Installation

1. Installez et activez le plugin WordPress situé dans `ide-snippets-bridge/`.
2. Dans WordPress, créez un mot de passe d’application dans **Utilisateurs > Profil**.
3. Dans l’extension IDE, ajoutez une connexion avec :
   - URL du site
   - Nom d’utilisateur WordPress
   - Mot de passe d’application

### Fonctionnalités principales

- Lister, créer, modifier, activer et désactiver des snippets.
- Cibler les snippets globalement ou par contenu.
- Importer et exporter les snippets (JSON / NDJSON).
- Gérer plusieurs sites WordPress depuis les outils IDE.
